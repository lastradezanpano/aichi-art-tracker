# 愛知アート帳

愛知県内の美術館・博物館・ギャラリーの展覧会と、アニメ・マンガの原画展／コラボカフェ／ポップアップストアなどのイベントをまとめる静的Webサイトです。「東海お笑いライブ帳」と同じ構成（GitHub Pages＋GitHub Actions）で運用します。

## 公開・更新

- GitHub Pagesで一般公開（スマホからURLを開くだけで閲覧できる）
- GitHub Actionsが毎日7:00（日本時間）ごろに自動更新（遅れることがある）
- Actions画面の Update and deploy から手動更新も可能
- ページは開いた日の日付（日本時間）で表示するため、データ更新が止まっても会期終了分は自動で消え、「残りわずか」等の表示も正しく出る

## 自動で取得するもの／しないもの

| 情報源 | 自動取得 | 内容 |
|---|---|---|
| artscape（愛知） | する | 展覧会名・会場・会期。新規分は詳細ページの住所で市区町村を判定し、愛知県外は除外 |
| 原画展.info（愛知タグ） | する | 原画展の名称・会期（一覧）と会場（詳細ページ） |
| コラボカフェ.com 等 | しない | 複数会場の自由記述で機械的に正しく判定できないため。既存データは残し、会期終了分だけ自動で消える |

- 自動取得は「新規追加」と「同じ情報源の会期更新」だけを行う。既存データの `category`・`note`・`url` は書き換えない。
- 日付が確定していない展示（例:「会期：公式サイト参照」）は載せない。
- 取得に失敗した情報源があっても既存データは消さない。結果は `data/scrape_status.json` に残る。
- コラボカフェ等の新規追加は、必要なときだけClaude Codeで `update_prompt.md` を実行して補う（手動）。

## 構成

- `index.html` … サイト本体（`data/events.json` を読み込んで表示）
- `data/events.json` … イベントデータ
- `data/scrape_status.json` … 毎回の実行結果。失敗調査はまずここを見る
- `scripts/update_events.py` … 自動取得・更新スクリプト（標準ライブラリのみ）
- `.github/workflows/update-and-deploy.yml` … 毎日の自動更新と公開
- `sources.json` … 情報源一覧
- `update_prompt.md` … 手動補完用のClaude Code向け手順

## ローカル確認

`preview.ps1` をPowerShellから実行し、`http://127.0.0.1:8766/index.html` を開きます。

## 注意

- ローカルで `scripts/update_events.py` を試すときは、`--data` に別のコピーを指定する（指定しないと `data/` の実データを上書きする）。
- パスワード・Cookie・APIキーは保存しない。公開ページのみ利用する。
